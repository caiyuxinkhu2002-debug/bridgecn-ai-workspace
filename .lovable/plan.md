# BridgeCN AI 전체 진단 & 오늘의 개선안

## 1. 서비스 흐름 스캔 결과

### 지금 잘 되어 있는 것
- 결제(Paddle) + 쿼터 인프라, 이메일 인프라, SEO/legal 페이지, MCP OAuth — 백엔드 뼈대는 실서비스급.

## 2. 오늘 착수할 1개 — **G1 + G2 부분: "프로젝트 컨텍스트 브릿지"**

가장 근본이고, 이거 하나로 G3·G4·G5 체감이 같이 올라감.

### 무엇을 만드나
1. **현재 프로젝트 컨텍스트 훅** `useCurrentProject()` — 상단 `ProjectContextBar` 가 이미 잡은 활성 프로젝트를 모든 모듈에서 재사용. 카테고리·타깃 오디언스·톤을 하나의 소스에서 읽음.
2. **KOL Discovery 자동 매칭**: 현재 프로젝트가 있으면 카테고리 칩과 매칭 파라미터가 프로젝트 설정으로 프리필 (지금은 수동 필터). "Project: 뷰티 X" 배지 노출 + "필터 초기화" 링크.
3. **Consumer Insight / Localization / Launch Checklist**: 페이지 상단에 프로젝트 요약 스트립(브랜드명·카테고리·타깃·단계) 추가. 각 페이지의 AI 프롬프트에 프로젝트 컨텍스트 자동 주입 (지금은 수동 입력).
4. **대시보드 프로젝트 카드 강화**: 각 프로젝트 카드에 "다음 액션 1줄" + 최근 스냅샷/숏리스트 카운트 노출.
5. **빈 프로젝트 감지**: 프로젝트 0개면 KOL/Insight 페이지에서 `/start` 로 유도하는 CTA 카드.

### 손대는 파일 (예상)
- 신규: `src/lib/workspace-context.tsx` 확장 or `src/lib/project-context.tsx` (활성 프로젝트 훅)
- 신규: `src/components/project-summary-strip.tsx`
- 수정: `src/routes/_app.kol-discovery.index.tsx` (프로젝트 카테고리 프리필)
- 수정: `src/routes/_app.consumer-insight.tsx`, `_app.localization-studio.tsx`, `_app.launch-checklist.tsx` (요약 스트립 삽입 + AI 컨텍스트 주입)
- 수정: `src/routes/_app.index.tsx` (프로젝트 카드에 진행률 · 다음 액션)
- 수정: `src/lib/ai/project-context.ts` (활성 프로젝트 자동 병합)

### 손대지 않을 것 (오늘)
- 결제 flow, 이메일, MCP, 크롤 파이프라인, 리포트 PDF, 모바일 리레이아웃 — 다음 마일스톤.

### 검증 방법
1. `/start` 에서 프로젝트 하나 생성 → 카테고리 "뷰티/스킨케어" 선택.
2. `/kol-discovery` 진입 → 뷰티 칩이 자동 선택되어 있고 상단에 프로젝트 배지가 보임.
3. `/consumer-insight` 진입 → 상단에 프로젝트 요약 스트립이 뜨고, AI 생성 시 브랜드명·카테고리가 결과에 반영됨.
4. `/` 대시보드 → 해당 프로젝트 카드에 "다음: 消费者 인사이트 확인" 문구 노출.
