## 2. 섹션별 재작성 지침 (핵심 요지)

### Executive Summary
- 배경 설명 금지. 다섯 개 짧은 단락 + 3~5개 불릿.
- 정의 / 타깃 / 문제 / 지금인 이유 / 신뢰 근거 순.

### 페인 포인트
- 3~4개 페르소나별 문제를 카드형으로.
- "누가 / 무엇이 어려운가 / 기존 도구가 왜 부족한가 / 왜 지금 풀어야 하는가".

### 시장 컨텍스트
- TAM/SAM/SOM은 페인의 근거로만 사용. 짧은 데이터 인용 위주.

### 솔루션 / 제품
- Workflow 다이어그램 1장 + 모듈별 1페이지 1개념.
- 각 모듈: 입력 → 처리 → 검증 → 출력 → 측정 가능한 결과.
- 스크린샷 캡션도 통일된 문장체로 재작성.

### 비즈니스 모델
- 표: 플랜 / 대상 고객 / 지불 이유 / 가격 / 핵심 가치.
- Unit Economics는 CAC·LTV·Payback을 짧은 문단으로.

### 기술
- 버즈워드 제거. "데이터 출처 → AI 활용 방식 → 검증 방식 → 리스크" 4블록.
- SEMrush Verified 배지, 프롬프트 검증, 휴먼 리뷰 루프 강조.

### 리스크
- 5개 리스크 (데이터 신뢰성 / 플랫폼 정책 / AI 환각 / 규제·컴플라이언스 / 상용화) 각각 What · Why · Mitigation 3열 표.

### Conclusion
- 반복 요약 금지. "왜 할 가치가 있는가 / 왜 지금인가 / 왜 실행 가능한가" 3문단.
