# KOL 자동 추천 — "브랜드 전용 KOL 플랜"

## 결론부터
네, 가능합니다. 지금은 KOL 페이지가 "카탈로그 + 필터"라서 사용자가 직접 고르는 구조입니다.
앞 단계(브랜드 입력 → 웹사이트 자동 추출 → 시장 → 경쟁사 → 소비자/현지화)에서 이미 모아둔
프로젝트 컨텍스트를 KOL 매칭 엔진에 그대로 넘겨서, **"이 브랜드에게 지금 이 12명"** 을
자동으로 뽑아주는 화면을 추가합니다.

## 만드는 것

### 1) 자동 추천 패널 (KOL 페이지 최상단)
- 프로젝트가 있으면 진입 즉시 **"{브랜드}를 위한 추천 KOL"** 블록이 먼저 뜸.
- 티어별로 묶어서 제시 (예산 배분이 바로 보이게):
  - 리딩 KOL 1~2명 (인지도) / 미드티어 4~6명 (전환) / 마이크로 6~10명 (리뷰 볼륨)
- 각 카드에 **추천 이유 한 줄** 표시 — "카테고리 일치(스킨케어) · 오디언스 20-29 여성 일치 · 예산 내".
- 하단에 합계: 예상 총 집행비(¥ 범위), 합산 도달, 플랫폼 분포.
- 버튼 2개: **"이 플랜을 숏리스트로 저장"** (일괄 추가) / **"직접 고르기"** (기존 카탈로그로 스크롤).

### 2) 추천 근거를 앞 단계 데이터로 강화
현재 매칭은 `knowledgeBase.category/industry/keywords` 정도만 씁니다. 여기에 추가로 주입:
- 소비자 인사이트 단계의 타깃 오디언스(연령·성별·도시 티어)
- 경쟁사 단계의 경쟁 브랜드명 → KOL의 `mentioned_brands` 와 대조해 **"경쟁사 협업 이력"** 가점
- 시장 인사이트 단계의 우선 플랫폼(小红书 vs 抖音) → 플랫폼 가중치
- 프로젝트 예산 입력(신규, 선택) → 티어 구성 자동 산출

### 3) 매칭 점수 투명화
카드에 category / audience / platform / price 4개 축 점수를 그대로 보여주고,
실측 필드와 AI 추정 필드를 지금처럼 구분 유지 → "장난감" 인상 제거.

### 4) 프로젝트 없을 때
`/start` 로 유도하는 CTA 유지. 프로젝트 생성 직후 KOL 단계로 오면 바로 추천이 채워짐.

## 기술 노트
- `src/lib/kol/match.functions.ts` 확장: 입력에 `competitorBrands`, `preferredPlatforms`,
  `budgetTotalCny` 추가. 점수식에 경쟁사 이력 가점 + 티어 분류(followers 구간) 로직 추가.
- 신규 `src/lib/kol/plan.ts`: 점수 순 결과를 티어별 예산 배분으로 잘라 "플랜" 구성 (순수 함수, 서버 호출 없음).
- 신규 `src/components/kol/recommended-plan.tsx`: 추천 패널 UI + 일괄 저장.
- 수정 `src/routes/_app.kol-discovery.index.tsx`: 패널 삽입, 기존 필터는 아래로 유지.
- 수정 `src/lib/kol/kols.functions.ts`: `addToShortlist` 를 여러 건 처리하는 `addManyToShortlist` 추가.
- 추천 이유 문구는 점수 축에서 규칙 기반으로 생성 (AI 호출 없음 → 쿼터 소모 0, 결과 재현 가능).

## 검증 방법
1. `/start` 에서 뷰티 브랜드 생성 → 웹사이트 자동 추출까지 완료.
2. `/kol-discovery` 진입 → 상단에 추천 12명이 티어별로 자동 표시되는지 확인.
3. "이 플랜을 숏리스트로 저장" → `/projects/:id` 숏리스트에 일괄 반영 확인.
4. 예산을 낮춰서 재계산 → 리딩 KOL이 빠지고 마이크로 비중이 늘어나는지 확인.
