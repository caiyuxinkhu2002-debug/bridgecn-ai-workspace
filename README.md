## 🇬🇧 English

### What is this?

**China Market Insight** turns a brand name + a category into a structured, sourced market-entry brief for Greater China (Mainland 🇨🇳 / HK 🇭🇰 / TW 🇹🇼) and adjacent APAC markets (KR 🇰🇷 / JP 🇯🇵 / IN 🇮🇳).

Every claim is either:

- 🟢 **Verified** — pulled live from SEMrush with a provenance badge `Verified · SEMrush · {market} · {timestamp}`, **or**
- 🟡 **AI inference** — generated by Lovable AI and **clearly labeled** as a category benchmark (no fake institution names, ever).

### ✨ Key Features

| | Feature | Why it matters |
|---|---|---|
| 🟢 | **Verified data layer** | Live SEMrush pulls with provenance badges — no hallucinations |
| 🤖 | **AI report generation** | Multi-section briefs: KPIs, segments, channels, competitors, risks |
| ⚡ | **Self-healing jobs** | Stale `ai_jobs` (>5 min) auto-reaped server-side; UI never hangs |
| 🗺️ | **Smart market routing** | Regex-based mapping → `mainland` / `tier 1` / `hk` / `tw` / `kr` / `jp` / `in` |
| 🌐 | **Full i18n** | EN · 中文 · 한국어 across the entire UI |
| 🔒 | **Hardened RLS** | Workspace-scoped policies; role escalation blocked; emails admin-only |
| 🏷️ | **No fake sources** | Generic "AI inference (category benchmark)" label when live data unavailable |

### 🔒 Security

- ✅ **RLS enabled** on every public-schema table with explicit `GRANT`s
- ✅ **User roles** in a dedicated `user_roles` table with `SECURITY DEFINER` `has_role()` check (never on profiles)
- ✅ **Service-role key** never reaches the client — used only inside `*.server.ts`
- ✅ **Role escalation blocked** — admins cannot promote anyone to `owner`
- ✅ **Member emails** visible only to workspace admins/owners
- ✅ **SECURITY DEFINER helpers** revoked from `anon`/`authenticated` direct execution
- ✅ **Stale jobs** auto-reaped via `reap_stale_ai_jobs()` (SECURITY INVOKER)

## 🇨🇳 中文版

### 这是什么？

**China Market Insight** 是一个 AI 驱动的中国市场情报平台。输入「品牌名 + 品类」，自动生成一份**带数据来源**的市场进入简报，覆盖大中华区（大陆 🇨🇳 / 香港 🇭🇰 / 台湾 🇹🇼）和邻近亚太市场（韩国 🇰🇷 / 日本 🇯🇵 / 印度 🇮🇳）。

每条结论都明确标注：

- 🟢 **已验证** — 来自 SEMrush 实时数据，附带溯源徽章 `Verified · SEMrush · {市场} · {时间}`
- 🟡 **AI 推断** — 由 Lovable AI 生成，**明确标注**为品类基准（绝不编造机构名称）

### ✨ 核心功能

| | 功能 | 价值 |
|---|---|---|
| 🟢 | **真实数据接入** | SEMrush 实时拉取 + 溯源徽章，杜绝幻觉 |
| 🤖 | **AI 报告生成** | 多维度市场简报：规模 / 渠道 / 竞品 / 风险 |
| ⚡ | **任务自愈** | 卡死任务（>5分钟）后端自动回收，UI 永不卡死 |
| 🗺️ | **智能市场映射** | 正则路由 → 大陆 / 一二线 / 港 / 台 / 韩 / 日 / 印 |
| 🌐 | **完整国际化** | 中文 · English · 한국어 全 UI 覆盖 |
| 🔒 | **强化 RLS** | 工作区隔离 · 防权限提升 · 邮箱仅管理员可见 |
| 🏷️ | **零虚假来源** | 无真实数据时，统一标为「AI 推断（品类基准）」 |
